# Password Generator

## Description
Script **Python** qui automatise la création de mots de passe solides en combinant
des lettres majuscules/minuscules, des chiffres et des caractères spéciaux.

## Prérequis
- Python 3.x
- Les modules `random` et `string` sont natifs à Python, aucune installation requise.

## Utilisation

**Via le terminal :**
```bash
python main.py
```

**Via PyCharm :**
Ouvre le fichier `main.py` et clique sur le bouton **Run**.

Entrez le nombre de mots de passe souhaités, puis la longueur pour chacun.

## Exemple de résultat
```
Combien de mots de passe voulez-vous générer ?: 2
Entrer la longueur du mot de passe 1: 12
>>MDP n1: J55CaJLp7pO/
Entrer la longueur du mot de passe 2: 9
>>MDP n2: Q=o<M+9fZ
```
